# MySQL共享会话底座（阶段66.2）

`MySQLSessionStore`保存有界JSON快照、到期时间和不透明CAS版本令牌。每次写入必须给出读到的版本；已改变的版本明确冲突，不自动重试。令牌随机生成，因此删除/过期后重新创建的同名会话也不会接受旧写者（避免ABA）。每次读取重新取数据库记录，不提供进程内回退。

同namespace的最大条数和TTL必须一致。MySQL事务串行核对配额与写入；到期时间使用服务器UTC。清理只删除已过期、且没有被MySQLCoordinator会话锁持有的记录，不能因清理误删仍在执行的会话。配额满时拒绝新会话；单快照最大1MiB，不静默截断。协调器与存储必须使用相同namespace，并留足独立池连接，避免协调租约占满存储池。

写入过程中出现取消或结果不确定时关闭数据库连接，不回收未确认事务；若提交结果未知，调用者必须先读再判断，不能盲目补写。存储异常不包含原始payload。事务回滚和opaque版本令牌只解决存储层冲突，不替代查询期间的会话互斥或模型费用审计。

真实测试包括两个独立写进程竞争同一版本、另一个新进程读取、过期重建后的旧版本拒绝、全局配额、活跃过期会话保护、配置不一致、损坏JSON、事务取消和快照边界。所有数据库均为自有随机fixture。

阶段66.3已增加查询、会话GET、版本编辑与回滚的可选接线，见[共享查询路径](shared-query-runtime.md)。部署启动尚未激活该运行时；还需连接恢复、配置失效、索引所有权和丢锁取消。默认运行路径未改变，多worker整体仍未验收。
