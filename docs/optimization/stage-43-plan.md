## 选择与范围

本地缓存模型manifest摘要为sha256:85462619ee721b466c5927d109d4cb765861907d5417b9109caebc4e614679f1，模型层文件621867104字节。拟收集53个唯一输入（23文档+30问题），共3803 UTF-8字节，最长165字节；每文本一次POST，另在前后各一次GET核对服务端模型摘要，共最多55次环回HTTP请求。并发1、无重试/回退/自动拉取，单推理30秒、元数据10秒、worker总600秒另加5秒清理，独占新运行目录；各阶段写入后检查64MiB产物预算，这不是硬文件系统配额。仅向http://127.0.0.1:11434发送冻结合成文本，不读取业务数据库或上传凭据。

## 实施步骤与验收

1. 先补失败回归：维度/非有限向量、manifest/模型/题集漂移、超额请求、重复运行、取消和索引版本不符；准备模式不得导入SDK、建立HTTP客户端或调用模型。
2. 生成冻结输入/源码/模型/参数/资源清单和摘要，执行必须确认精确manifest SHA；只支持受限本地profile，不扩大旧模型4次上限。先登记请求再发送；未知传输结果不自动重试。每次运行新目录，不盲目复用旧/半写向量或索引。
3. 向量缓存仅作为本次测量的精确输入产物，以模型摘要、维度、文本/题集身份绑定；缺失/重复/维度错误/非有限值拒绝，不作为生产语义缓存功能。索引与模型版本不一致时拒绝复用；重建失败不得覆盖旧可用索引。
4. 真实执行前完成CLI、报告、故障/Schema链路验证及完整离线门禁；列出具体manifest并取得路线要求的执行授权。授权前完成其余可独立工作，不提前推理。授权后按一次性清单运行，记录全部物理调用、无缓存embedding收集/索引构建/暖检索耗时（不宣称模型冷启动）、分层质量、缓存身份、缺测与清理。无法运行则明确待授权/缺测，不能以mock声称真实embedding验收通过。
5. 运行全量离线、真实双库82项、Ruff/原与新增strict、类型债务新增0、182前端与完整构建。更新阶段报告与路线，普通推送并核验同SHA的两项CI，补记文档再核验最终SHA。真实部分未完成时不将阶段43总表标记已验收，不合并main。
